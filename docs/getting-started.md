# Getting started

## Requirements

- macOS 14 Sonoma or later.
- About 100 MB of disk space for the app. The optional photo-search model needs more; see [model](model.md).

## Install

1. Download `Branchway-<version>.dmg` from the [Releases](../../../releases) page.
2. Open the disk image and drag Branchway to Applications.
3. Open Branchway.

## First launch

Onboarding has five steps:

1. A welcome.
2. **Keyboard profile**: macOS, Windows or Power User (start from macOS and remap everything).
3. **Places**: the folders Branchway starts from. Granting a folder here may show a macOS permission prompt.
4. **Full Disk Access**: optional. It lets Branchway read protected locations such as Mail or Safari data in
   views like Storage. You can grant it later in System Settings › Privacy & Security.
5. A few preferences, then "Open Branchway".

After onboarding, a short tour rings the address bar, sidebar, view options, search, inspector and tabs.
Skip it any time with Esc. Replay it with Help › Show Tour Again. Help › Show Onboarding Again repeats the
onboarding.

## The window

- **Sidebar**: Home, Favorites, iCloud, Locations (disks, Storage, Large Files), Vaults and Tags.
- **Band**: back and forward, the address bar (⌘L to type a path), search, the view selector, sort and
  group, and the inspector toggle.
- **Tabs** under the band. ⌘T opens one, ⌘W closes it.
- **Views**: list (⌘1), icon (⌘2), column (⌘3) and gallery (⌘4) on the macOS profile.
- **Dual pane**: ⌥⌘2. Tab switches panes. ⌥⌘B syncs browsing between them.
- **Inspector**: ⌥⌘I.
- **⌘K** opens the command palette.

The [keyboard shortcuts](keyboard-shortcuts.md) page lists every binding in the three stock profiles.
