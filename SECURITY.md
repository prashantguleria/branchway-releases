# Security

If you find a security problem in Branchway, please email **security@evenpine.com** (address to be
confirmed before this repository is made public) rather than opening a public issue. Include the Branchway
version, your macOS version and steps to reproduce.

We will acknowledge your report and keep you informed. Please give us reasonable time to fix a problem
before sharing details.

Releases are code-signed, notarized and signed with Sparkle EdDSA keys. Never download Branchway from
anywhere but this repository's Releases or evenpine.com.
