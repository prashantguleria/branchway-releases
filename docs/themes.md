# Themes and icons

Open Settings › Appearance.

- **Light or dark** follows your Mac.
- **Theme**: Default, Evenpine, Graphite Ember and Paper Lantern. A theme sets colours, typography and
  the icon set that goes with it.
- **File icons**: each theme brings an icon pack.
- **Folders above files**: sorts folders before files. It is off by default and can be toggled from the
  View menu (⌥⌘F).

A theme changes how Branchway looks, not what it does. No feature is removed in any theme.
