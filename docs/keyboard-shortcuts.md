# Keyboard shortcuts

Branchway ships three stock keymap profiles. Choose one in onboarding or in Settings › Keyboard. The stock
profiles are fixed so that a screenshot and a support answer mean the same thing on every Mac. **Custom**
starts from macOS and lets you remap any command; you can import and export a keymap as JSON. Help ›
Keyboard Shortcuts shows the bindings of your current profile.

Symbols: ⌃ Control, ⌥ Option, ⇧ Shift, ⌘ Command.

- **Windows** is the macOS profile with the changes marked in the second column.
- **Commander** is the Windows profile with the function-key changes marked in the third column.
- A dash means "same as the column to its left".

Notes:

- Return renames on the macOS profile and opens on the Windows and Commander profiles, as in Finder and
  File Explorer.
- On the Windows and Commander profiles ⌘1 to ⌘4 jump to places and ⌃1 to ⌃4 change the view.
- Commands that are not in the table (for example Redo) are in the menu bar next to their commands.

Source of this table: the shipped keymap tables in the app, checked against the app's source on the date
of this document. If a shortcut differs on your Mac, Help › Keyboard Shortcuts is authoritative.
