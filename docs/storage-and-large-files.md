# Storage and Large Files

Both live under Locations in the sidebar.

## Storage

A map of what takes up space on a disk or in a folder, drawn as tiles.

- Tile colours match the legend categories (documents, images, video and so on).
- Click a tile to go deeper; the breadcrumb takes you back up.
- Reading protected locations (for example Mail or Safari data) needs Full Disk Access.
- Files that are only stored in the cloud (not downloaded) are shown but never downloaded by the scan.

You can also open Disk Usage from the View menu, from a folder's context menu and from ⌘K.

## Large Files

A list of the biggest files, biggest first, up to 500 rows. It answers from Branchway's index when the
index is ready and walks the disk when it is not, without opening any file.

- Folders, packages, links, vaults and anything inside a vault or package are left out.
- Cloud files that are not downloaded are listed and are never downloaded.

## Deleting

Branchway moves items to the Trash. Empty the Trash when you are sure.
