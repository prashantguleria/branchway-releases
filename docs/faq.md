# FAQ

## Which languages does Branchway speak?

The interface is available in 16 languages and follows your system language. Natural-language (sentence)
search understands English only.

## What does it cost?

Branchway is a paid app with a 14-day free trial. See evenpine.com for the current price.

## Does it replace Finder?

No. It is a separate file manager. Reveal in Finder works, and Branchway can be offered as the app that
shows folders when other apps reveal files, where macOS allows it.

## Does it work on external drives and network shares?

Yes for anything macOS mounts. NTFS volumes are read-only through macOS itself. Write support is in
development and is not part of the current release.

## Is my data sent anywhere?

No. See [privacy](privacy.md).

## Does it run on Windows or Linux?

No. Branchway is for macOS 14 or later.

## Can I use Windows or Total Commander shortcuts?

Yes: choose a keyboard profile in Settings › Keyboard. See [keyboard shortcuts](keyboard-shortcuts.md).

## Where do I report a bug?

Open an issue in this repository using the bug template.
